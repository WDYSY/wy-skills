# ttd_lang_locale_cover - Design Spec

> Cover-only demo: one slide, generated by the ppt-master-trip pipeline, using an
> AI-generated hero background. Scope confirmed with the user: 首页封面 only.

## I. Project Information

- **Project name**: ttd_lang_locale_cover
- **Product**: Trip.com 门票业务（T 站）海外流量分析
- **Deliverable**: single cover slide（首页封面）with AI background image
- **Audience**: 门票业务运营 / 增长团队
- **Purpose**: 数据报告的封面页，用一张 AI 生成的深色氛围底图承载标题与核心结论数字
- **Content divergence**: 封面只承载口径与一个核心结论，不展开正文

## II. Canvas Specification

- **Format**: PPT 16:9
- **Dimensions**: 1280x720
- **viewBox**: `0 0 1280 720`

## III. Visual Theme

### Theme Style

- **Style**: dark-tech — 深色电影感底图 + 克制的排版，文字压在画面最平静的左侧区域
- **Mood**: 专业、数据感、低光源

### Color Scheme

| Role | HEX | Usage |
|------|-----|-------|
| Background | #0A1220 | 页面底色 / 左侧压暗渐变 |
| Primary | #2E8BFF | 分隔线、结构强调 |
| Accent | #F5A623 | 数字与关键结论 |
| Text | #F2F7FF | 标题 |
| Text Secondary | #9FB3CC | 副标题、标签、页脚 |
| Border | #1E3350 | 细分隔线 |

### AI Image Strategy

- **Rendering**: vector-illustration
- **Palette**: dark-cinematic
- **Strategy**: 仅一张 `hero_page` 背景图（`cover_bg.png`），画面主体集中在右三分之一与底部，左侧与中部保持平静以承载 SVG 文字；图像本身不含任何文字。

### Gradient Scheme

```xml
<linearGradient id="coverScrim" x1="0" y1="0" x2="1" y2="0">
  <stop offset="0%" stop-color="#0A1220" stop-opacity="0.72"/>
  <stop offset="58%" stop-color="#0A1220" stop-opacity="0.35"/>
  <stop offset="100%" stop-color="#0A1220" stop-opacity="0"/>
</linearGradient>
```

## IV. Typography System

### Font Plan

- **font_family**: `"Microsoft YaHei", "PingFang SC", Arial, sans-serif`（PPT 安全栈：落底 Arial）

### Font Size Hierarchy

| Role | Size (px) | Usage |
|------|-----------|-------|
| cover_title | 64 | 主标题 |
| hero_number | 48 | 结论数字 |
| subtitle | 28 | 副标题（口径） |
| body | 24 | 备用正文 |
| annotation | 20 | 眉标 |
| footnote | 16 | 数字标签、数据源页脚 |

## V. Layout Principles

### Page Structure

- 左侧文字栏：x = 88，安全宽度 ≈ 470px（图像在 x < 600 区域为纯深色，亮度均值约 25/255）
- 右侧 40%：交给底图的球面网格、弧线与光柱

### Spacing Specification

- 左右安全边距 88px；页脚距底 46px
- 眉标 → 主标题 92px；主标题 → 副标题 88px；副标题 → 结论数字行 204px

## VI. Icon Usage Specification

封面不使用图标。

## VII. Visualization Reference List

封面不放图表；柱状/光柱语义由底图承担。

## XI. Technical Constraints Reminder

### SVG Generation Must Follow:

- viewBox 与 width/height 一致；背景用 `<rect>` 或全幅 `<image>`
- 只使用 `spec_lock.md` 中的颜色与字体
- 不使用 `rgba()`、`<g opacity>`、`mask`、`class`、`<style>`、`foreignObject`
- 一个逻辑行 = 一个 `<text>`，行内强调用不带 x/dy 的嵌套 `<tspan>`

### PPT Compatibility Rules:

- 图片用 `<image href="../images/cover_bg.png" preserveAspectRatio="xMidYMid slice"/>`，导出前由 `finalize_svg.py` 内嵌
