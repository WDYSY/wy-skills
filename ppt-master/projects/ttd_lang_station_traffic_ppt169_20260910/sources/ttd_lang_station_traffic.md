# T 站门票语言站流量分析

数据齐了，给你按语言站口径重新梳理的完整结论。

**口径说明**（数据截止 2026-08-17，最近完整 7 天 8/10-8/17）：

- **环境**：SGP 集群（T 站海外数据）
- **表**：`dw_ticketdb.edw_log_ttd_traffic_order_d_ext`，过滤 `page_ct='trip'` + `sub_bu_name='ibu门票'`
- **"站点"口径**：按 `locale` 字段（语言站，如 zh-hk=香港繁体、en-sg=新加坡英文）
- **指标**：PV = `count(distinct com_pv)`，UV = `count(distinct vid)`；流量来源 = `trip_channel`
- 上一轮按景点（viewspotname）答偏了，这次按语言站重新统计

## 各语言站流量来源对比

## 关键解读

- **zh-hk（香港）站内占比高达 66.6%**，是所有站里最高的——香港用户多在平台内自发流转（跨业务跳转/历史访问），对外投放依赖低；Partner 联盟是第二抓手（13.3%）
- **en-sg（新加坡）是 APP-PUSH 依赖度最高的站**（23%），且 PV 体量全站第二——新加坡站高度依赖 Push 召回，很可能与 BIGBANG 新加坡演唱会等演出的开票提醒强绑定
- **ru-ru（俄语站）流量结构最特殊**：SEO 占 28.4%（全站最高）远超其他渠道，说明俄罗斯用户大量通过搜索引擎自然流入，对投放依赖低
- **ko-kr（韩语）和 en-my（马来）相对均衡**：站内 44-55%，Partner/PPC/SEO 各占 8-16%，多渠道并进
- 整体看，**站内仍是大盘主力**（各站 32%-67%），对外投放里 Partner 联盟 + SEO + APP-PUSH + PPC 是四个主要抓手，但**每个语言站的投放侧重差异巨大**，运营策略应该一站一策
