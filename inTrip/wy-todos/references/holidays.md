# 工作日判定与节假日表

判定规则：**周一～周五 且 不在下表** 才算工作日。周末与下表日期既不算「本周剩余」的可用时间，也不该出现在「本周任务」的日期标签里。

## 2026

| 假期 | 日期 |
|---|---|
| 元旦 | 01-01 ~ 01-03 |
| 春节 | 02-16 ~ 02-22 |
| 清明 | 04-04 ~ 04-06 |
| 劳动节 | 05-01 ~ 05-05 |
| 端午 | 06-19 ~ 06-21 |
| 中秋 | 09-25 ~ 09-27 |
| 国庆 | 10-01 ~ 10-08 |

## 2027

| 假期 | 日期 |
|---|---|
| 元旦 | 01-01 ~ 01-03 |
| 其余 | 国务院放假通知通常在上一年 11~12 月发布，**跨年前必须回来补全** |

## 维护说明

- 调休上班日（周末补班）目前不计入工作日；如果王妍按调休上班，把它当作正常工作日处理，在表里加一条 `--makeup` 说明。
- 表里没有的年份不要瞎猜，先按官方通知核对再跑，宁可在卡片上标注「节假日表未覆盖 X 年」。
