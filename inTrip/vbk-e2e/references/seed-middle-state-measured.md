## 必须写进流程的三条修正

1. **列表页默认停在「有可售班期」页签**：中间态产品没有米期，直接搜 ID 会「暂无数据」；**先切「全部」再搜**，或者干脆按 URL 直开候选。
2. **DB 条件缩不到「两页签」这一档**：`Active='F'/IsOnline='F'/Name=''` 既可能是两页签（8911072），也可能是五页签（8913824）。**页签数与「复制」按钮只能在页面上判**；判定失败就换下一个候选。
3. **复制产物比源再早一档**：源 8911072 是「销售控制 + 产品信息」；复制出来的 2145289681 只有「销售控制」可点，**「产品信息」是灰的**，要先在销售控制保存一次才会亮。所以「只亮两个页签」的起点 = 复制后再把销售控制保存一次。
4. **复制成功前端会 `window.open` 新窗口**；内置浏览器/无扩展环境下这个弹窗可能被拦，**不要只等自动开窗**——用 DB（`CreateTime` 近 5 分钟）或直接按新 ID 打开确认。
